竹筏港水道四大地理區段（由北至南）

1. 北竹筏港－國聖港區段（曾文溪以北） 已成魚塭

今七股區三股一帶，昔日與國聖港銜接之出海口。戰後闢為約 480 公頃「七股魚塭（美國塭仔）」，古水道痕跡已消失。

2. 北竹筏港－土城仔區段（曾文溪至鹿耳門溪） 現存排水道

今安南區土城西側，由自然溪道疏濬而成、路徑曲折。今轉型為嘉南大圳「溪筏港線之一」（長 2,385 公尺）。

3. 南竹筏港－媽祖宮區段（鹿耳門溪至四草湖） 人工運河/隱溪

清代三郊人工開鑿之筆直運河（長約 1,300 公尺），經本田路一段、港仔寮至四草大道，現多為狹小排水溝或路面下隱溪。

4. 南竹筏港－四草湖區段（南端總匯） 諸水匯集處

古台江內海最後遺跡。東南接「舊運河（北幹線）」通往府城五條港，西南為古安平港出海口，日治時期闢為安順鹽場。

道光3年（1823）曾文溪改道使台江內海陸浮後，府城三郊疏通並開鑿「竹筏港水道」，串聯國聖港、鹿耳門溪、四草湖與五條港，成為清代中葉至日治初期台江最重要商貿動脈。
